# Exercise: Working with Countries Data

Using the provided countries JSON data, complete the following exercises.

### 1. Find All Unique Languages
Extract all the languages spoken in the countries data and combine them into a single list.

- Remove duplicate languages.
- Find the total number of unique languages.
- Sort the languages alphabetically.

### 2. Create a List of Cities
Create a list containing the capital cities of all countries in the data.

- Each city should appear only once.
- Sort the cities alphabetically.

### 3. Calculate the Total World Population
Calculate the total population of all countries in the dataset.

- Add the population of every country.
- Display the result as the total world population.
